Admin setup guide

One-time setup. Accounts, data and emails run in your own Google account.

  1. Open script.google.com → New project and delete the sample code.
  2. then paste it into the project. At the top, replace CHANGE-ME with your private school access code (letters and numbers only — keep the quote marks), then click Save.
  3. Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Deploy, then Authorize access (Advanced → Go to … → Allow). Copy the Web app URL.
  4. Open config.js (in the same folder as index.html) in Notepad, paste the URL between the quotes and save.
  5. Drag the whole folder (index.html and config.js) onto your site's Deploys page on Netlify again. Done — tutors can register with the access code.

The copied code already contains this site's address () for password-recovery emails.
